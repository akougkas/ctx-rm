Purpose: Replace manual "run bench 50 times" workflow with a single reproducible command.

Create `src/ctx_rm/benchmarks/experiment.py` with:

1. **ExperimentConfig** (Pydantic BaseModel) parsed from YAML:
   ```yaml
   # Example experiment config the model must parse:
   name: "eviction-comparison"
   output_dir: "./results/experiments"
   runs: 3                    # N repetitions per combination
   max_turns: 30
   tasks:                     # list of task IDs
     - SPEC-001
     - SCALE-001
   modes:                     # list of modes
     - ctx-rm
     - full
   policies:                  # list of policies (used only in ctx-rm mode)
     - budget
     - lru
   budgets: []                # empty = use BUDGET_MAP auto; list of ints to sweep
   scorer: heuristic          # single scorer for all runs
   enable_recall: true
   ```
   Fields: name (str), output_dir (str, default "./results/experiments"), runs (int, default 3),
   max_turns (int, default 30), tasks (list[str]), modes (list[str]), policies (list[str],
   default ["budget"]), budgets (list[int], default []), scorer (str, default "heuristic"),
   enable_recall (bool, default False).

   Add a classmethod `from_yaml(path: Path) -> ExperimentConfig` that reads the YAML file
   and validates via `model_validate`.

2. **Combination dataclass** `RunConfig`:
   Fields: task_id, mode, policy (str | None), budget (int), run_index.

3. **`generate_combinations(config: ExperimentConfig) -> list[RunConfig]`** function:
   - For each task x mode x policy x budget x run_index(1..N):
     - If mode != "ctx-rm": policy=None, budget is ignored (BenchmarkRunner handles full/minimal)
     - If mode == "ctx-rm" and budgets is empty: budget=0 (signals auto from BUDGET_MAP)
     - If mode == "ctx-rm" and budgets is non-empty: one combination per budget value
   - Dedup: full/minimal modes should appear once per task per run (not repeated per policy)
   - Return flat list sorted by (task_id, mode, policy, budget, run_index)

4. **`RunResult` dataclass**:
   Fields: config (RunConfig), passed (bool | None), prompt_tokens (int), completion_tokens (int),
   eviction_count (int), recall_count (int), recall_precision (float), error (str | None).

5. **`ExperimentRunner`** class:
   - `__init__(self, config: ExperimentConfig)` - stores config
   - `async def run_all(self, on_progress: Callable | None = None) -> list[RunResult]`:
     Iterates combinations from `generate_combinations`, creates a `BenchmarkRunner` for each,
     calls `runner.run()`, reads `evaluation.json` and `metrics.json` from the result directory,
     populates `RunResult`. Wraps each in try/except — on failure, sets error field.
     Calls `on_progress(completed, total, run_config)` after each run.
     The result_dir follows BenchmarkRunner's convention (read from `runner._result_dir()`).
     For budget=0 (auto), pass `token_budget=100_000` without `--budget` flag (i.e., don't set
     _explicit_budget) so runner auto-selects from BUDGET_MAP.
   - `aggregate(results: list[RunResult]) -> list[AggregatedResult]` (staticmethod):
     Groups by (task_id, mode, policy, budget), computes:
       - median_prompt_tokens (from statistics.median)
       - pass_rate (passes / total as float 0-1)
       - median_eviction_count
       - median_recall_count
       - mean_recall_precision
       - num_runs, num_errors

6. **`AggregatedResult` dataclass**:
   Fields: task_id, mode, policy (str | None), budget (int), median_prompt_tokens (float),
   pass_rate (float), median_eviction_count (float), median_recall_count (float),
   mean_recall_precision (float), num_runs (int), num_errors (int).

Add a new `experiment` command to `src/ctx_rm/cli/main.py`:

```python
@app.command()
def experiment(
    config_path: Annotated[Path, typer.Argument(help="YAML experiment config file.")],
    dry_run: Annotated[bool, typer.Option("--dry-run", help="Show combinations without running.")] = False,
) -> None:
```

Implementation:

1. **Load config**: `ExperimentConfig.from_yaml(config_path)`.
2. **Generate combinations**: Call `generate_combinations(config)`.
3. **Dry-run mode**: If `--dry-run`, print a Rich table of all combinations (task, mode, policy,
   budget, run_index) and exit. Useful for verifying config before long runs.
4. **Run all**: Create `ExperimentRunner(config)`, call `await runner.run_all(on_progress=...)`.
   Wire `on_progress` to print a progress line: `[3/24] SPEC-001 ctx-rm budget run-1 ... done`.
   Use `asyncio.run()` to bridge sync CLI to async runner.
5. **Aggregate**: Call `ExperimentRunner.aggregate(results)`.
6. **Rich table**: Build a Rich Table with columns:
   Task | Mode | Policy | Budget | Median Tokens | Pass Rate | Evictions | Recalls | Recall Prec | Runs | Errors
   - Pass rate: green if 1.0, yellow if >0, red if 0
   - Evictions/Recalls: cyan if >0 and mode=ctx-rm
   - Budget: "auto" if budget=0, else formatted int
   Print to console.
7. **CSV export**: Write `{output_dir}/experiment_results.csv` using stdlib `csv.writer`.
   One row per AggregatedResult. Header row matches table columns.
   Print the CSV path to console.
