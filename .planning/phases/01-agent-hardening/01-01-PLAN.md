<task type="auto">

  <files>src/ctx_rm/agents/tools.py</files>

Modify src/ctx_rm/agents/tools.py to implement all four tool upgrades:

TOOL-01 — done tool:
- Add to TOOL_DEFINITIONS: name="done", description="Signal task completion with a structured result", parameters: summary (string, required, "Brief description of what was accomplished"), files_changed (array of strings, optional, "List of files created or modified").
- Add _done handler to ToolExecutor: accepts {"summary": str, "files_changed": list[str] | None}, returns JSON string: {"status": "done", "summary": "...", "files_changed": [...]}. Use orjson.dumps for serialization.
- Add "done": self._done to the handler dispatch dict in execute().

TOOL-02 — file_read line ranges:
- Add start_line (integer, optional, "1-based line number to start reading from") and end_line (integer, optional, "1-based line number to stop reading at, inclusive") to file_read's parameters in TOOL_DEFINITIONS.
- Modify _file_read: after reading content, if start_line or end_line is provided, split into lines, slice [start-1:end], and prefix each line with its 1-based line number (f"{line_num}: {line}"). CRITICAL: If NEITHER start_line NOR end_line is provided, return content as-is with NO line numbers. This preserves backward compatibility — line numbers are ONLY added when a range parameter is explicitly provided.
- Handle edge cases: start_line < 1 clamps to 1, end_line > len(lines) clamps to len(lines), start > end returns empty.

TOOL-03 — grep_search filters:
- Add include (string, optional, "Glob pattern for file types, e.g. '*.py'"), max_results (integer, optional, "Maximum number of matching lines to return"), context_lines (integer, optional, "Number of context lines before and after each match") to grep_search's parameters in TOOL_DEFINITIONS.
- Modify _grep_search: Replace the hardcoded --include=*.py --include=*.js ... list with dynamic include handling. If args has "include", use single --include={value}. If no include, use the existing default list. If args has context_lines, add -C {n} to grep args. After getting results, if max_results is set, truncate output to that many match lines (lines not starting with --), appending "... [truncated to {max_results} results]" if truncated.

TOOL-04 — run_shell exit code + cwd:
- Add cwd (string, optional, "Working directory override for the command") to run_shell's parameters in TOOL_DEFINITIONS.
- Modify _run_shell: If args has "cwd", resolve it and use as subprocess cwd (instead of self.working_dir). Always include exit_code in output as a structured suffix: "\n[exit_code: {returncode}]" — even for exit code 0 (currently only shown for non-zero). This makes it consistently parseable.

After implementing, run `uv pip install -e .` to reinstall.
