<objective>
Upgrade the agent loop to handle done-tool termination, use a real system prompt, log each turn, and inject failure hints.

Purpose: The agent loop currently terminates only when the model stops making tool calls (returns text). This is unreliable — the model might return commentary mid-task. The done tool gives explicit termination. The system prompt guides effective tool usage. Turn logging enables post-run analysis. Failure hints prevent the agent from spinning on the same error.

Output: Updated loop.py, runner.py, and extended test_loop.py covering LOOP-01 through LOOP-04.
</objective>

LOOP-01 — System prompt:
- Replace the minimal `_build_system_prompt` with a comprehensive one. The prompt must:
  1. Tell the agent it's a coding agent that completes tasks using tools
  2. Teach read-before-write workflow: always read a file before modifying it
  3. Teach partial reads: use start_line/end_line for large files instead of reading everything
  4. Teach grep with filters: use include and max_results to avoid flooding context
  5. Teach change verification: after writing/patching a file, read back the changed section to confirm
  6. Teach done signaling: when task is complete, call the done tool with summary and files_changed
  7. Do NOT mention context management, eviction, budgets, or anything about the ctx-rm system

  Example structure:
  ```python
  def _build_system_prompt(self, task: Task) -> str:
      return "\n".join([
          "You are a coding agent. Complete the assigned task using the available tools.",
          "",
          "## Workflow",
          "1. Read files to understand the codebase before making changes.",
          "2. For large files, use start_line and end_line to read specific sections.",
          "3. Use grep_search with include and max_results to find relevant code efficiently.",
          "4. After modifying a file, read back the changed section to verify your edit.",
          "5. When the task is complete, call the done tool with a summary of what you did.",
          "",
          "## Tool Tips",
          "- file_read: Use start_line/end_line for partial reads of large files.",
          "- grep_search: Use include='*.py' to filter by file type, max_results=10 to limit output.",
          "- file_patch: The old_text must be unique in the file. Read first to find the exact text.",
          "- run_shell: Check exit codes. A non-zero exit code means the command failed.",
          "- done: Call this when the task is complete. Include summary and files_changed.",
          "",
          "## Task Scenario",
          task.scenario.strip(),
      ])
  ```
